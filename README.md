# Weather App
Приложение погоды с поиском по городу.

## Ссылка 
https://weather-tq4d.vercel.app

## Технологии
- React + TypeScript
- Zustand
- React Query + Axios
- OpenWeatherMap API

## Функционал
- Поиск погоды по городу
- Температура, влажность, ветер, ощущается как
- Иконка погоды
- Сохранение последнего города

## Запуск
npm install
npm run dev
